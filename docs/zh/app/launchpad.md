# 比特币原生发行平台

Inscrib3 发行平台可让钱包创建固定供应的 Arkade 资产，打开 BTC 绑定曲线，并逐渐进入永久的全范围池。资产发行、启动融资、购买和出售均在 Inscrib3 钱包中批准和签署。该应用永远不会收到助记词或私钥。

::: warning 仅限Mutinynet
公共发行平台处于实验阶段，目前在 **Mutinynet** 上运行。测试BTC和资产没有主网价值。检查每个钱包的批准并验证资产 ID。
:::

## 启动生命周期

|相|会发生什么 |
| --- | --- |
|`preparing`|钱包发行唯一的控制资产和固定的代币供应，然后准备原子启动引导程序。 |
|`curve`|买家和卖家根据 BTC 绑定曲线进行交易。 |
|`graduating`|如果结算中断，则将对最终填充进行核对。它不是一个单独的用户资助市场。 |
|`pool`|该发布已自动移入其规范永久池中。 |
|`failed`或`rescued`|失败或恢复的发射是终结的，不会呈现为活跃市场。 |

标准泳池不能提前开放。唯一的控制资产保留在曲线契约中，并且只有当代币储备达到为毕业保留的数量时，契约才允许过渡到不可变池脚本。

## 创建启动

打开 **启动 → 创建启动**，然后：

1. 选择启动 ID、显示名称、股票代码、描述和代币小数点；
2. 输入固定的原始供应量、虚拟BTC和毕业门槛；
3. 审查创建者和协议费率；
4. 在创建任何资金请求之前模拟精确的曲线项；
5. 批准钱包中唯一控制资产和代币供应的发行；
6. 批准打开曲线并支付启动创建费的原子引导程序。

目前 Mutinynet 的启动创建费用为 **10,000 sats**。部署配置和钱包审批具有权威性。

名称和股票代码**不是唯一的**。代币的可验证身份是其完整的`assetId`；启动 ID、控制资产和契约地址标识关联的启动状态。

## 结合曲线

曲线定价使用恒定乘积不变量：

```text
(virtual BTC + real BTC reserve) × token reserve = k
```

虚拟BTC会影响定价，但不是真正的契约余额，无法提取。真实比特币是买家贡献的结算储备金，扣除适用的费用和退款。

在为交易提供资金之前，详细信息页面会显示确切的整数报价、产量、费用以及购买是否达到毕业标准。钱包为支付约束请求契约提供资金；协调器无法替换承诺的接收者或最小输出。

### 最终购买和退款

最终买家不需要购买比曲线上可用的代币更多的代币。如果提交的 BTC 超过达到预留代币余额所需的金额，结算将执行部分填充，并在同一原子转换中将未使用的 BTC 返回给买家。

## 原子毕业

当曲线达到其预留代币余额时，最终交易和毕业发生在一笔交易中：

- 曲线状态被消耗；
- 剩余的预留代币和真实的BTC转移到预定的池脚本中；
- 规范永久池成为下一个状态；
- 支付任何最终填充退款；
- 不存在任何中间状态可供另一方获取官方储备。

永久启动池是一个恒定产品、全范围的市场，没有LP代币、存款分支或取款分支。其主要流动性不能通过启动契约移除。毕业后，交易将通过相同的发布详细信息页面继续进行。

## 规范市场和外部市场

Inscrib3 阻止在其官方 API 和界面中创建通用池来启动资产。此检查发生在池控制、LP 或分类账资产发行之前以及返回引导程序地址之前。

基础资产和通用 AMM 契约仍然无需许可。持有者仍然可以将代币转移到 Inscrib3 之外的合约或市场。这样的市场：

- 不是规范的启动池；
- 不持有发射控制资产或毕业储备；
- 不能改变曲线或规范分级；
- 可能具有不相关的流动性、费用、安全性和定价。

此产品级限制可以保护官方用户体验，而无需引入授权工厂、管理员密钥或许可的 AMM 契约。

## 费用和平台收入

每次发布都会记录不可变的费用条款。当前的创建形式默认为：

- **0.70% 创作者费用**，支付至配置的创作者费用金库；
- **0.30% 协议费**，支付给 Inscrib3 协议库；
- **10,000 sats 创建费**，在发布开始时支付。

签署前必须检查显示的条款和钱包交易。协议费用在曲线和永久池上继续。 Inscrib3 不保管交易本金或永久池储备。

## 积分和活动

- 开放式发布可获得 **10 积分**；
- 已结算的启动交易每 SAT 协议费可赚取 1 点，最低 1 点；
- 失败、无资金或退款的请求不会赚取积分；
- 符合条件的推荐操作可获得一个幂等推荐点。

启动购买和销售显示在**我的活动**中，包括启动 ID、地点、金额、状态、交易和积分。参见[积分和主网迁移](/zh/app/points)。

## 发现和图表

发布目录支持最新、趋势和毕业进度视图。 **On Fire** 识别过去 24 小时内最活跃的启动，且至少存在 3 个已结算交易。

发布详细信息图表形成了横跨绑定曲线和永久池的连续价格历史记录。它标记了每个场地并标志着毕业。曲线价格包含虚拟BTC进行定价；联营价格使用实际储备。

## 恢复和安全重试

资金和结算是异步的。应用在本地存储可恢复的启动进度，API 记录资金、开户、结算、退款和对账。

如果付款已发送：

- 不再发行资产；
- 不要资助第二次更换它的请求；
- 使用保存的交易ID重试注册或开通；
- 仅当请求符合条件时才使用退款操作；
- 检查**我的活动**以及恢复后的启动状态。

在资助启动之前，继续了解[App 风险和故障排除](/zh/app/security)。
