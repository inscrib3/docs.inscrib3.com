# 开始使用 Mutinynet

## 1.安装浏览器扩展

从 Chrome 应用商店[安装 Inscrib3 钱包](https://chromewebstore.google.com/detail/inscrib3/hafphignbjdmblopkophkohgnphalclg)，或将应用安装为 PWA 并连接其托管钱包 Provider 窗口。两种方式均支持余额/MAX、兑换、流动性、资产发行、流动性池创建和发行项目创建。使用 PWA 时请保持钱包窗口打开；每个资金或签名请求都会在其中显示，等待明确批准。

离线备份钱包助记词。切勿将其粘贴到应用或任何网站中。

## 2. 选择 Mutinynet

打开钱包设置并选择 **Mutinynet**。当钱包和 API 网络不匹配时，公共 App 会拒绝交易请求。

Mutinynet 地址以`tark1…`开头。未来的主网部署使用不同的运营商和地址，而可移植点身份使用独立于网络的专用帐户密钥。

## 3. 获取测试资金

仅使用 Mutinynet 测试 BTC 和测试资产。打开应用之前，请确认它们在扩展程序中显示为可用。

::: danger
不要将主网 BTC 发送到 Mutinynet 地址。测试资产没有保证价值，绝不应被视为投资。
:::

## 4. 连接应用

打开[app.mutinynet.inscrib3.com](https://app.mutinynet.inscrib3.com)，选择 **连接钱包**，在扩展程序中查看来源，并批准连接。

标头必须显示 **MUTI​​NYNET**。每次批准之前，请验证钱包显示的来源、资产、金额、网络和目的地。

## 5. 选择一个动作

- **交换：** 选择一对，输入输入或所需输出，审查费用、影响、滑点和积分，然后批准资金。
- **流动性池：** 检查储备、价格历史、活动、费用和控制供应警告。
- **添加/删除：**按池比例贡献资产或按比例赎回LP资产。
- **创建：**发行资产或引导无许可池。
- **启动：**检查或创建固定供应代币，在其 BTC 曲线上进行交易，并随后进入永久流动性。
- **活动：** 检查您的请求、分数、排名、细分和排行榜。

在等待结算扫描期间，请求可能仍会得到资助。不要仅仅因为请求不是即时的而重复请求；首先检查**活动**下的状态。
