# 资金池和流动性

## 恒定产品池

每个池都持有基础储备和报价储备，并根据其比率进行价格兑换。初始创建者通过初始准备金率确定开盘价格。更深的储备通常会减少价格影响，但不会消除智能合约、资产或市场风险。

池页面显示标准化现货价格方向、储备、有限合伙人供应、应计费用、历史图表和结算活动。

## 增加流动性

从池中选择**添加**。输入基本金额；该应用计算当前准备金率所需的报价金额并预览收到的LP资产。资金受契约约束并异步结算。

流动性Provider面临资产及其相对底价变化的风险。费用并不能保证提供流动性是有利可图的。

## 消除流动性

选择 **删除**，输入要赎回的 LP 金额，然后查看按比例的基础和报价输出。请求在结算后完成，并根据池合约销毁或消耗赎回的LP头寸。

## 创建一个池

从**创建 → 创建池**：

1. 选择不同的基础资产和报价资产；
2. 以显示单位输入初始储备；
3. 查看派生池 ID 和显示名称；
4. 在允许的限度内选择总费用和协议费用；
5. 审查初始流动性、技术载体、创建费用和总资金；
6. 批准钱包中的单一原子引导支付。

当前 Mutinynet 创建费用为 **10,000 sat**。应用返回的配置是权威的，并且在未来的部署中可能会有所不同。

打开的池可赚取 **10 积分**。从未达到`opened`的请求不会获得积分。

## 受控和可再发行资产

具有`controlAssetId`的 Arkade 资产可以由控制该资产的人重新发行。该应用会显示受控供应警告，因为未来的发行可能会极大地改变流动性池经济状况。该警告仅供参考，并非认可或风险评分。

始终验证完整的资产 ID。名称和股票代码并不是唯一的身份。

## 启动资产和通用池

Inscrib3 launchpad 注册的资产不能用于通过官方 App 或 API 创建通用池。在发行任何特定池的资产之前，应用会检查该货币对； API 独立拒绝注册并且不返回引导地址。

启动资产通过其绑定曲线进行交易，并在原子毕业后通过其规范的永久池进行交易。此限制适用于 Inscrib3 产品表面，而不适用于无需许可的 AMM 契约。外部市场在技术上仍然是可能的，并且不被规范或认可。请参阅[比特币原生发行平台](/zh/app/launchpad)。
