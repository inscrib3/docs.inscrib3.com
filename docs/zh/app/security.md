# 应用风险和故障排除

::: danger 实验性 MUTINYNET 软件
目前的应用、协调器和合约都是在 Mutinynet 上运行的早期软件。仅使用测试资金。可用性、池状态和 API 在测试期间可能会发生变化。
:::

## 每次审批前

- 仅使用[app.mutinynet.inscrib3.com](https://app.mutinynet.inscrib3.com)；
- 确认钱包显示 **Mutinynet** 和`tark1…`地址；
- 验证来源、资产、原始/显示金额、费用和目的地；
- 检查滑点和价格影响；
- 验证资产 ID，而不仅仅是名称或股票代码；
- 阅读受控供应警告；
- 切勿在应用中输入助记词。

## 主要风险

- **实验合约：**缺陷可能会产生意外的结算或退款行为。
- **流动性风险：** 储备不足可能会产生较高的价格影响。
- **资产风险：**控制`controlAssetId`的发行人可能会创造额外的供应。
- **启动风险：**曲线参数、费用、毕业门槛、预留流动性一旦融资就不可更改；流行的名称或股票代码并不能证明身份或质量。
- **外部市场风险：** 持有者可以在 Inscrib3 之外创建市场。只有启动时预先确定的永久池才是规范的。
- **异步结算：**资助请求等待扫描并且不是即时的。
- **基础设施风险：** API、Ark服务器、索引器或 Mutinynet 可能不可用。
- **测试网重置：** Mutinynet 状态没有与比特币主网相比的永久性保证。

## 常见问题

### “将 Inscrib3 钱包切换到 MUTINYNET”

扩展程序位于错误的网络上。在钱包设置中更改其网络，然后重新连接或刷新。

### 请求仍处于资助状态

检查**我的活动**并等待结算扫描。除非第一个请求已达到最终状态，否则不要创建重复的请求。

### 泳池不可用

刷新池状态。合约、Ark服务器、API或所需储备可能暂时不可用。不要通过在线返回的池来推断安全性。

### 我的积分不见了

只有开放的池或启动以及已结算的池或启动交易才有资格。确认该操作的终端状态以及连接的钱包是为其提供资金的钱包。积分自动刷新；如果需要，请使用活动刷新控件。

### 启动付款已发送，但开仓或交易未完成

不要发行另一个代币供应，也不要支付第二个请求。保留保存的交易 ID，重试相同的打开或注册流程，并检查启动和 **我的活动** 状态。仅当应用报告资助请求可退款时才使用退款。
