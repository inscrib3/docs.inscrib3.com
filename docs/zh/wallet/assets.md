# 创建、重新发行和销毁资产

Inscrib3 钱包可以创建 Arkade 资产，增加配置为可重新发行的资产的供应，并永久销毁活跃账户持有的单位。这些操作在浏览器扩展程序和网页钱包中都可用。

::: warning
资产操作广播真实交易。确认前请检查活跃账户、网络、资产 ID 和金额。首先在 Mutinynet 上测试不熟悉的流程。
:::

## 金额和小数

Arkade 将资产金额记录为整数**原始单位**。小数仅控制钱包如何显示这些单位。

对于具有两位小数的资产：

|显示金额 |原始单位|
| ---: | ---: |
| `1.00` | `100` |
| `25.50` | `2,550` |

在创建、重新发行或销毁资产之前，钱包会显示原始单位预览。小数不会改变资产的基础供应。

## 创建资产

从钱包主屏幕中，选择 **创建资产**，然后提供：

- **名称：** 1–64 个字符；
- **股票代码：** 1–16 个字母、数字、点、下划线或破折号；
- **小数：** 0 到 18 之间的整数；
- **初始供应量：** 正数，小数位数不超过配置的精度；
- **图标 URL：** 可选的 HTTP 或 HTTPS 图像 URL。

在确认之前检查元数据、显示的供应量、原始供应量和补发设置。成功发行会返回一个新的68个字符的资产ID和一个可以在浏览器中打开的创建交易。

::: info
资产元数据是发行的一部分，以后无法从钱包中编辑。远程图标 URL 由发行者控制，加载时可能会泄露查看者的 IP 地址。
:::

## 固定或可重新发行的供应

默认情况下，资产是固定供应的。要允许额外供应，请在创建过程中启用**可重新发行供应**，并选择钱包持有的现有资产作为其**控制资产**。

控制资产定义再发行权限：

- 钱包必须持有一定数量的控制资产才能重新发行；
- 转让控制资产可以转让增发权；
- 如果多个钱包持有控制资产的单位，则每个持有者都可以授权额外的供应；
- 发行后不得新增或更换控制资产；
- 创建新的供应不会消耗或烧毁控制资产。

如果钱包没有可供控制的资产，则先创建固定供应资产，然后将其作为后续发行的控制资产。

::: danger
将控制资产视为管理密钥。失去对每个单元的访问权限将导致您无法重新发行；将单位发送给另一方可以赋予该方相同的权力。
:::

## 重新发行资产

从主屏幕打开资产。 **重新发行**仅当资产是使用控制资产创建并且活动钱包当前持有该控制资产时才会出现。

1. 选择**重新发行**。
2. 输入附加显示金额。
3. 验证原始单元预览。
4. 选择**确认重新签发**。

新单位添加到资产供应中，钱包刷新其余额和活动。如果不再持有所需的控制资产，则补发失败。

## 烧毁资产

活跃账户持有的任何资产单位都可以被销毁；不需要控制资产。

1. 打开资产并选择 **刻录**。
2. 输入金额，或选择**最大**以使用全部持有余额。
3. 验证原始单元预览。
4. 确认刻录是永久性的，然后选择**永久刻录**。

燃烧会通过摧毁选定的单位来减少供应。不可撤销，且金额不能超过钱包余额。

## 应用集成

连接的应用可以通过`window.arkade`请求相同的操作。每个请求都会在扩展中打开一个专用的批准窗口。有关参数、返回值、验证和示例，请参阅[asset API 指南](/zh/provider/assets)。

PWA Provider窗口支持余额和资产发现、发送现有资产以及发行、重新发行和销毁生命周期。金额仍然是原始安全整数，可选的 BTC 载体是明确的，每个状态更改请求都需要在钱包窗口中获得批准。
