# 愿景与方向

我们希望通过隐藏复杂性而不隐藏其工作原理的产品，使比特币的可编程性变得实用。

## 方向

Inscrib3 的新阶段重点关注使用 Arkade 构建的开源应用。钱包是第一个节点：它为用户提供了自托管界面，并为应用提供了与之交互的Provider。

### [现已上市 — Inscrib3 钱包](/zh/wallet/overview)

使用 Arkade 构建的浏览器扩展和可安装的 PWA。

## 接下来会发生什么

公共路线图有意保持下一个节点开放：

- **下一个版本：**新产品准备就绪后将发布；
- **未来的实验：** 提供真正实用性的比特币原生应用的空间。

::: info
我们不会发布未经确认的日期或功能。路线图描述的是产品方向，而不是交付承诺。
:::

## 构建原则

1. **比特币作为基础。** 不要创建替代区块链。
2. **产品先于叙述。**将技术可能性转化为可用的体验。
3. **开源。** 使代码和决策可验证。
4. **自托管。** 让用户控制他们的密钥。
