# 我们的旅程

我们当前的方向源于多年来对基于 UTXO 的协议的研究。这项工作不会被取代：它是我们今天所建设的基础。

### 1. 2023年——协议访问

我们通过钱包体验使新兴的 UTXO 协议变得更加平易近人，包括[Inspip](https://github.com/inscrib3/inspip)（PIPE 的浏览器扩展）。

### 2. 2024 年——开放基础设施

我们为[PIPE](https://github.com/inscrib3/pipe-indexer)、[Flux](https://github.com/inscrib3/flux-indexer)和[BlokAI](https://github.com/inscrib3/blokiai-indexer)构建了开源索引器，将协议活动转化为应用可以使用的数据。

### 3. 2025年——开发者工具

TypeScript SDK、React 库和参考实现使我们的 Ordinals 基础设施更接近产品团队和开发人员。

### 4. 今天——Arkade方向

我们从钱包、索引器和 UTXO 协议中学到的一切现在预示着一个新阶段：使用 Arkade 构建的开源产品。
