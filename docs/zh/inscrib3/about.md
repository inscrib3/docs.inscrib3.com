# 什么是 Inscrib3

Inscrib3 是一个独立的产品构建团队。我们探索比特币输出架构的潜力，并将协议和基础设施转变为人们和开发人员可以使用的产品。

## 我们的论文

当可编程性创造实用性时，它就变得有价值。我们的工作处于以下交叉点：

### 可编程性

扩展比特币交易的功能。

### 公用事业

将技术可能性转化为可访问的应用。

### 开源

公开建设，以便可以共同测试和改进想法。

## 比特币、Arkade、Inscrib3

我们的模型明确区分了每个角色：

|层 |角色 |
| --- | --- |
|比特币 |货币和结算基金会|
|Arkade |可编程比特币应用的开放执行环境|
|铭文3 |面向用户和面向开发人员的产品和界面|

::: info
Arkade由Ark Labs独立开发。 Inscrib3 使用它来构建产品；它并没有创造Arkade。
:::

## 我们在公共场所建造

我们相信有用的比特币基础设施通过实验、透明度和协作而发展。我们的项目可在[Inscrib3 GitHub 组织](https://github.com/inscrib3)中找到。
