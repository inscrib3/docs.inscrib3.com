# 开源项目

Inscrib3 发布其钱包、用户界面、网站和文档，以便可以独立检查、复制和改进它们。

|项目|制作网址 |存储库 |
| --- | --- | --- |
| Inscrib3 钱包 |[wallet.inscrib3.com](https://wallet.inscrib3.com)|[inscrib3/arkade-wallet](https://github.com/inscrib3/arkade-wallet)|
| Inscrib3 应用前端 |[app.mutinynet.inscrib3.com](https://app.mutinynet.inscrib3.com)|[inscrib3/app.mutinynet.inscrib3.com](https://github.com/inscrib3/app.mutinynet.inscrib3.com)|
|主要网站 |[inscrib3.com](https://inscrib3.com)|[inscrib3/inscrib3.com](https://github.com/inscrib3/inscrib3.com)|
|文档 |[docs.inscrib3.com](https://docs.inscrib3.com)|[inscrib3/docs.inscrib3.com](https://github.com/inscrib3/docs.inscrib3.com)|

## “开源”可以让你验证什么

- 钱包密钥处理和批准边界；
- 向应用公开的Provider方法；
- 客户端报价处理、池显示和积分接口；
- 部署工作流程和为用户提供的确切前端代码；
- 文档历史记录和更正。

开源提高了透明度，但并不能保证软件没有缺陷。使用前请查看[应用风险指南](/zh/app/security)和[钱包安全模型](/zh/wallet/security)。
