# Open-source projects

Inscrib3 publishes its wallet, user interfaces, website, and documentation so they can be inspected, reproduced, and improved independently.

| Project | Production URL | Repository |
| --- | --- | --- |
| Inscrib3 Wallet | [wallet.inscrib3.com](https://wallet.inscrib3.com) | [inscrib3/arkade-wallet](https://github.com/inscrib3/arkade-wallet) |
| Inscrib3 App frontend | [app.mutinynet.inscrib3.com](https://app.mutinynet.inscrib3.com) | [inscrib3/app.mutinynet.inscrib3.com](https://github.com/inscrib3/app.mutinynet.inscrib3.com) |
| Main website | [inscrib3.com](https://inscrib3.com) | [inscrib3/inscrib3.com](https://github.com/inscrib3/inscrib3.com) |
| Documentation | [docs.inscrib3.com](https://docs.inscrib3.com) | [inscrib3/docs.inscrib3.com](https://github.com/inscrib3/docs.inscrib3.com) |

## What “open source” lets you verify

- wallet key handling and approval boundaries;
- provider methods exposed to Apps;
- client-side quote handling, pool presentation, and points interfaces;
- deployment workflows and the exact frontend code served to users;
- documentation history and corrections.

Open source improves transparency but is not a guarantee that software is defect-free. Review the [App risk guide](/app/security) and [wallet security model](/wallet/security) before use.
