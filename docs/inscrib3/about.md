# What is Inscrib3

Inscrib3 is an independent product-building team. We explore the potential of Bitcoin's output architecture and turn protocols and infrastructure into products that people and developers can use.

## Our thesis

Programmability becomes valuable when it creates practical utility. We work at the intersection of:

### Programmability

Expanding what can be built with Bitcoin transactions.

### Utility

Turning technical possibilities into accessible applications.

### Open source

Building in public so ideas can be tested and improved together.

## Bitcoin, Arkade, Inscrib3

Our model clearly separates each role:

| Layer | Role |
| --- | --- |
| Bitcoin | Monetary and settlement foundation |
| Arkade | Open execution environment for programmable Bitcoin applications |
| Inscrib3 | User-facing and developer-facing products and interfaces |

::: info
Arkade is independently developed by Ark Labs. Inscrib3 uses it to build products; it did not create Arkade.
:::

## We build in public

We believe useful Bitcoin infrastructure grows through experimentation, transparency, and collaboration. Our projects are available in the [Inscrib3 GitHub organization](https://github.com/inscrib3).
