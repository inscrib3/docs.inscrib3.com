# Vision and direction

We want to make Bitcoin programmability practical through products that hide complexity without hiding how they work.

## The direction

Inscrib3's new phase focuses on open-source applications built with Arkade. The wallet is the first node: it gives users a self-custodial interface and Apps a provider to interact with.

### [Available now — Inscrib3 Wallet](/wallet/overview)

Browser extension and installable PWA built with Arkade.

## What comes next

The public roadmap intentionally keeps the next nodes open:

- **next release:** a new product will be revealed when it is ready;
- **future experiments:** room for Bitcoin-native applications that provide real utility.

::: info
We do not publish unconfirmed dates or features. The roadmap describes a product direction, not a delivery promise.
:::

## Building principles

1. **Bitcoin as the foundation.** Do not create an alternative blockchain.
2. **Products before narratives.** Turn technical possibilities into usable experiences.
3. **Open source.** Make code and decisions verifiable.
4. **Self-custody.** Give users control over their keys.
