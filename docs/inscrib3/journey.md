# Our journey

Our current direction grows out of years of work on UTXO-based protocols. That work is not being replaced: it is the foundation of what we build today.

### 1. 2023 — Protocol access

We made emerging UTXO protocols more approachable through wallet experiences, including [Inspip](https://github.com/inscrib3/inspip), a browser extension for PIPE.

### 2. 2024 — Open infrastructure

We built open-source indexers for [PIPE](https://github.com/inscrib3/pipe-indexer), [Flux](https://github.com/inscrib3/flux-indexer), and [BlokAI](https://github.com/inscrib3/blokiai-indexer), turning protocol activity into data applications could use.

### 3. 2025 — Developer tools

TypeScript SDKs, React libraries, and reference implementations brought our Ordinals infrastructure closer to product teams and developers.

### 4. Today — Arkade direction

Everything we learned from wallets, indexers, and UTXO protocols now informs a new phase: open-source products built with Arkade.
